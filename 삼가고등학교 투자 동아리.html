매매 입력실

직접 체결된 매수·매도 기록을 포트폴리오에 입력합니다.

Manual trades

수동 매매기록 입력

수량은 직접 입력할 수 있게 남겨두고, 체결가격을 적던 칸은 비중 계산용으로 바꿨습니다. 비중을 입력하면 BUY는 현재 총자산의 %, SELL은 현재 보유 수량의 %로 자동 계산하고, 비중을 비워두면 입력한 수량으로 체결합니다. 체결가격은 해당 시점의 가격 데이터에서 자동으로 가져옵니다.

가격 CSV를 불러오면 여기서 종목을 선택할 수 있습니다.
비중을 비워두면 이 수량으로 체결합니다.
BUY: 총자산의 %, SELL: 보유수량의 %. 가격은 자동 적용됩니다.
매매 CSV 권장 형식: datetime,symbol,side,qty,pct,fee,tax,memo · pct가 있으면 비중 기준, 비어 있으면 qty 수량 기준으로 처리합니다.

포트폴리오 매매기록

선택한 포트폴리오에 저장된 매매기록입니다.

정기 매수 규칙

매 거래일·매주 첫 거래일·매월 첫 거래일 기준으로 자동 매수 규칙을 저장합니다.

Recurring buy

정기 매수 규칙 입력

분석을 실행할 때 실제 가격 데이터가 있는 시점에 맞춰 자동 체결됩니다.

총자산 비중 기준일 때 입력합니다.
수량 기준은 입력 수량 그대로 매수하고, 총자산 비중 기준은 해당 시점의 현금 + 보유 평가액 중 입력한 %만큼 자동 매수합니다. 체결가격은 가격 데이터에서 자동 적용됩니다.
